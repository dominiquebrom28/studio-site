## Learnings

**A closed PR is not a closed session.** The most surprising thing the backfill
found is that PR #25 merging *concealed* unmerged work: because the branch's
first ten commits merged and closed the PR, the six-commit tail that came after
looked, from the PR list, like nothing was left. A run that ships a report would
have named the tail on the day. Two didn't-write-a-report failures compounded
into a two-day-invisible feature. This is the strongest argument yet for the
hard rule the session broke.

**"Backfill the record" turned into "audit the branch," and that's the point.**
The item read like clerical catch-up. Doing it mechanically against git —
`main...<tip>` rather than trusting the PR list — surfaced a finding no summary
would have. Same house pattern as everything else this month: the check only
works if you point it at the artifact, not at the story about the artifact.

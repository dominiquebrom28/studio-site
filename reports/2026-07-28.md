## Learnings

- **Check the real gate before sounding the alarm.** The single biggest time sink this run was treating raw `npm audit --audit-level=high` (exit 1, "7 high vulns", lockfile unchanged from `main`) as "CI is red for every PR." The actual gate is `npm run audit` (`audit-ci`), which **passes** — the "7" are two reviewed, allowlisted advisories fanned across seven packages. I spun up a security-auditor to fix a non-problem before verifying the command CI actually runs. The recovery was cheap (redirected the agent to a useful validation pass, which produced the one real improvement in PR #64), but the lesson is a run-playbook note (added to the backlog): *reconcile CI health with the command CI runs, not a lookalike.*
- **Verify a subagent's incidental facts before acting on them.** The security-auditor spot-checked brace-expansion and reported "only 5.0.8 installed, the 1.x copy deduped away," recommending I trim the allowlist comment. A direct `find` showed **both** overridden versions on disk (`1.1.16` nested under `minimatch`, `5.0.8` top-level) — the comment was accurate. Had I trusted the agent, an "align-to-reality" edit would have *introduced* an inaccuracy into the honesty-gate's own documentation. Agents are right most of the time; "most" is why you check the one that changes what you write.
- **The honest fix for a dead field can be to deliver it, not delete it.** Two defensible reads of "dead post `cover`": remove the cruft, or render the intention. The brief settled it — §5 explicitly wants a post cover — so removal would have discarded a real decision. But rendering a field zero content uses is its own mild declared-not-delivered risk, which is why the component test *exercises* the render with a fixture (falsified red-first) instead of shipping unfalsifiable code.
- **A backlog item can be wrong, and executing it faithfully would spread the error.** "Deprecate MarginNote (superseded by Callout)" was a plausible-looking cleanup that was factually incorrect. The studio has now hit "the instruction/gate is wrong, not the content" enough times (the same-day-post-order rule, the multi-author content gate) that suspecting the ask as hard as the code is becoming the house reflex.

## Learnings

- **The `npm install` drift trap bit again, exactly as the backlog predicted.** `@playwright/test` (added by PR #53) was never installed in the main checkout, so local `npm run typecheck` was red on files unrelated to any change — CI (`npm ci`) was green the whole time. A first agent could easily have burned time proving the breakage pre-dated its branch. Cost one `npm ci`. This is the second such incident (axe-core was the first) — the `post-checkout`/preflight fix is now clearly earning its place on the board.
- **A security review that hits a session wall is still worth running — you finish it, you don't re-run it.** The auditor's tools couldn't read a non-checked-out branch, but its reasoning on the reachable code (entry 1) was airtight and its list of exactly-what's-unverified turned the rest into three one-command shell checks. Splitting "reason about it" from "confirm the artifact" across two actors was faster than either doing both.
- **The flagship's hardest part was honesty about placement, not code.** The strip renders *both* "run of {date}" and "built on commit {hash}"; put a block in the wrong report and those two links contradict each other on the studio's own honesty device. The fix was a mechanical rule (block lives in the creating run's report) plus the discipline to leave two posts blank rather than invent a plausible home. "Review what stays blank" turned out to be the actual work.

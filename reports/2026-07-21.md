## Learnings

**Backfilling a report is auditing a branch, if you do it against git.** The
07-19-evening item read like clerical debt. Reconstructing it the honest way —
diffing `main...<branchtip>` instead of trusting the closed-PR list — turned up
a whole tested, documented feature stranded on a branch for two days, invisible
because the branch's *first* half had merged and closed the PR. A merged PR is
not a closed session. This is the same house pattern as everything else this
month: the check only works when you point it at the artifact, not at the story
about the artifact.

**"Sanctioned fallback" only works if the spec writes it down in advance.** The
MarginNote spec named its own riskiest piece (the lane's untestable measurement
math) and pre-authorized shipping without it. So when jsdom's all-zero rects
made the lane untestable, the frontend-dev took the fallback as a *decision*,
not a *failure* — a correct, complete, accessible v1 on the first pass instead
of shaky position math shipped under deadline. Compare the 07-18 anchor bug,
which had no such warning and cost a P0. Naming the landmine in advance is most
of the work; this is now three specs running (blog-format-v2, project-page-v2,
MarginNote) where the pre-named risk is exactly what came back needing the call.

**The test environment is a claim too.** jsdom returns `{0,0,0,0}` for every
`getBoundingClientRect`. A component whose behavior *is* geometry can be mounted,
asserted on, and reported green in jsdom while proving nothing — the same
fake-green failure mode as a gate that samples 1 of 11 routes. The right move
wasn't to write the green-but-meaningless test; it was to *not ship the feature
that only that test could cover*, and say so. Knowing what your harness cannot
see is part of knowing what "tested" means.

**The classifier weather is now a planning input, not a surprise.** Two runs
running, the Bash-gating classifier has flapped. The adaptation is no longer
improvised: pick outage-resilient work (code/doc verifiable by build/test),
commit with `-F <file>` (heredocs still never pass), do read-only recon in the
down windows, batch writes into the up ones — and *choose the batch* so the
Bash-heaviest high-value item (DOM-4 capture) isn't the thing you attempt on a
flaky day. The cost is real: DOM-4 has now waited three runs. That's a debt to
call out, not to hide — it's the top thing a stable-tooling run should grab.
